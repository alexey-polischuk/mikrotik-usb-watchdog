# История изменений (Changelog)

Все изменения проекта `mikrotik-usb-watchdog` фиксируются в данном документе.

---

## [2.1.0] - 2026-10-07

### Добавлено
* **Dual-Ping с устойчивыми к блокировкам в РФ узлами**:
  * Основной контрольный хост: `77.88.8.8` (Яндекс DNS).
  * Резервный контрольный хост: `195.208.4.1` (НСДИ — Национальная система доменных имен РФ / НИИ «Восход»).
  * Исключена уязвимость от блокировок Google DNS (`8.8.8.8`) и Cloudflare (`1.1.1.1`) на российских сотовых операторах.
* **Архивация версий**:
  * Добавлен каталог `archive/v1.0/` с исходным работающим скриптом первой версии.
* **Изоляция секретов**:
  * Создан шаблон `usb-watchdog-secrets.rsc.template` для хранения чувствительных URL и токенов Synology Chat.
  * Основной скрипт очищен от персональных данных и готов к безопасной публикации.

### Изменено
* **RAM-First архитектура (0 Flash Wear)**:
  * Рабочие счетчики бэкоффа и таймеры перенесены в глобальные переменные ОЗУ (`:global`).
  * Запись на Flash-память роутера (`/file set`) теперь происходит строго по событию (вход в бэкофф / восстановление связи). В нормальном режиме нагрузка на Flash снижена до **0 операций/сутки** (в v1.0 было ~2 880 операций/сутки).
* **Политики безопасности RouterOS**:
  * Скрипт логики `usb-watchdog-check`: `policy=read,write,test,reboot`.
  * Скрипт секретов `usb-watchdog-secrets`: `policy=read,test`.

---

## [1.0.0] - 2026-08-25

### Добавлено
* Первая рабочая реализация сторожевого таймера для модемов на RouterOS 7.24+ (RB2011).
* Одиночный ICMP-мониторинг (`77.88.8.8`) с порогом `failThreshold=4`.
* Сброс питания USB через `/system routerboard usb power-reset` с блокировкой `:do { ... } on-error={ ... }`.
* Экспоненциальный бэкофф (2 ч → 6 ч) с сохранением состояния в `usb-watchdog-state.txt`.
* Автоматическая отправка уведомлений в Synology Chat при восстановлении линка.
* Системная перезагрузка роутера (`/system reboot`) при исчерпании лимита циклов бэкоффа.
